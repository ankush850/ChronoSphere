# Feature: Custom Palette Theme Creator

Create personalized aesthetic color schemes directly inside the app.

---

## ⚙️ How It Works

1. **Color Pickers**: Interactive inputs for Background Base Color, Glow Accent Color, and Text Typography Color.
2. **Dynamic CSS Insertion**: Generates a runtime `<style id="custom-theme-styles">` tag injecting custom CSS variables into `[data-theme="custom"]`.
3. **Instant Persistence**: Saves custom palette preference to `localStorage` for immediate recall.
