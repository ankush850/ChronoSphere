# Feature: Live Weather & Ambient Focus Audio Generator

Integrated environmental awareness and productivity background sounds.

---

## ⚙️ How It Works

1. **Open-Meteo Weather API**: Fetches current temperature (°C) and weather condition icons using browser Geolocation or IP location fallback without requiring an API key.
2. **Web Audio Ambience Generator**: Generates continuous procedural audio loops for Rain 🌧️, Ocean Waves 🌊, 432Hz Binaural Focus 🧘, and White Noise 📻 with master volume slider.
