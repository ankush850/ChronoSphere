# Feature: Event Countdown Tracker

Track target dates and milestones with real-time countdown cards.

---

## ⚙️ How It Works

1. **Target Date Calculator**: Calculates difference `targetTime - currentTime` every second.
2. **Breakdown Display**: Deconstructs time difference into Days, Hours, Minutes, and Seconds.
3. **Card Management**: Add/remove upcoming events with `localStorage` persistence.
